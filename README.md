# Clean Calculator with History (Tkinter GUI)

This is a modern, user friendly calculator application built using Python and the `tkinter` GUI toolkit. It supports basic arithmetic operations and includes a history feature to review your recent calculations.

## Features

- Clean, minimalist GUI with custom styles
- Basic operations: addition, subtraction, multiplication, division
- Special functions: percentage, negate, decimal point
- Clear display and process tracking
- Recent calculations history (last 10 entries)
- Error handling (e.g. divide by zero)

## Technologies Used

- Python 3
- `tkinter` for the GUI
- `ttk` for styled widgets
- `collections.deque` for history management
